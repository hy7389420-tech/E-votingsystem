# Smart Secure E-Voting System

A responsive, dark glassmorphism frontend for a secure e-voting platform, built as a submission for **SIH 2026**.

## 🚀 Features

- 18 pages covering authentication, onboarding, voting, results, profile, help, and admin
- Dashboard with election summary cards, live status, and quick actions
- Candidate listing, vote confirmation flow, digital receipt view
- Results and voting history pages
- Profile and security settings pages
- Responsive layout (desktop and mobile)
- Custom dark theme with glassmorphism UI

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts

## ⚠️ Current Scope

This is the **frontend** of the project.

- Biometric (face, fingerprint, QR) screens are **UI flows only**. Real biometric verification is not implemented yet.
- Vote encryption and receipt hashing are **planned**, not production-ready.
- Backend (API and database) is the **next phase**.

## ▶️ Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/hy7389420-tech/E-votingsystem.git

# 2. Go into the project folder
cd E-votingsystem

# 3. Install dependencies
npm install

# 4. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build

```bash
npm run build
```
